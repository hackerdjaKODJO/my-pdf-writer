# Play Store 자산

`tools/make-store-assets.py`로 `docs/screenshots/`의 검증 스크린샷에서 생성한
Play Store 등록용 자산입니다. 스크린샷은 모두 **1080×2160 (1:2)** 로,
Play의 최대 2:1 비율 규격을 충족합니다.

## 구성

| 파일 | 규격 | 용도 |
| --- | --- | --- |
| `icon-512.png` | 512×512 PNG | 앱 아이콘 |
| `feature-graphic-1024x500.png` | 1024×500 PNG | 피처 그래픽 |
| `screenshots/01-home.png` | 1080×2160 | 광고 없이, 완전 오프라인 |
| `screenshots/02-annotate.png` | 1080×2160 | 강의자료 위에 바로 필기 |
| `screenshots/03-pages.png` | 1080×2160 | 페이지를 한 번에 정리 |
| `screenshots/04-rotate.png` | 1080×2160 | 회전해도 필기는 그대로 |
| `screenshots/05-search.png` | 1080×2160 | 찾고, 바로 해당 페이지로 |
| `screenshots/06-notes.png` | 1080×2160 | 페이지 메모로 복습까지 |
| `screenshots/07-export.png` | 1080×2160 | 주석이 새겨진 PDF로 내보내기 |

다시 생성:

```bash
python tools/make-store-assets.py
```

> 스크린샷은 Pixel 7 AVD(Android 16)에서 캡처한 실제 앱 화면입니다.
> 일부 화면은 개발 빌드에서 촬영했으며, 릴리스 빌드와 UI는 동일합니다.

## 앱 이름 (30자 이내)

```
My PDF Writer – 전공 필기 PDF
```

## 짧은 설명 (80자 이내)

```
광고 없이 오프라인으로 강의자료 PDF에 필기하고 정리해 내보내세요.
```

## 자세한 설명

```
강의자료 위에 바로 필기하고, 정리해서 PDF로 내보내세요.

My PDF Writer는 대학생의 전공 공부를 위해 만든 오프라인 PDF 작업대입니다.
광고도, 계정도, 인터넷 권한도 없습니다. 문서와 필기는 기기 안에서만 처리됩니다.

■ 필기
- 펜, 형광펜, 텍스트, 사각형, 화살표, 지우개
- 8색 팔레트와 굵기/글자 크기 조절
- 실행 취소/다시 실행

■ 페이지 정리
- 왼쪽/오른쪽 회전, 위/아래 이동
- 페이지 삭제, 빈 페이지 추가
- 원본 구성으로 한 번에 초기화
- 회전해도 필기 위치와 방향이 함께 유지됩니다

■ 공부에 맞춘 기능
- 페이지별 메모와 메모 목록
- PDF 텍스트 검색, 페이지별 결과와 바로가기
- 최근 문서 목록

■ 내보내기
- 화면에서 본 그대로 주석이 새겨진 PDF로 저장
- 한국어 텍스트, 형광펜 투명도, 회전된 페이지까지 동일하게
- 주석이 없는 페이지는 원본 PDF 그대로 유지

■ 프라이버시
- INTERNET 권한을 선언하지 않습니다
- 광고·분석·계정 SDK가 없습니다
- 파일은 Storage Access Framework로 사용자가 직접 선택합니다

지원: Android 8.0 이상
```

## 데이터 안전성 (Data safety)

| 항목 | 답변 |
| --- | --- |
| 앱이 데이터를 수집/공유하나요? | 아니요 |
| 데이터가 전송 중 암호화되나요? | 해당 없음 (서버 전송 없음) |
| 사용자가 데이터 삭제를 요청할 수 있나요? | 앱 삭제 시 앱 전용 데이터 삭제 (원본 PDF는 유지) |
| 광고 | 없음 |
| 계정 | 없음 |
| 분석/크래시 리포팅 SDK | 없음 |

릴리스 APK의 권한은 앱 자체의 `DYNAMIC_RECEIVER_NOT_EXPORTED_PERMISSION` 하나뿐입니다.
`INTERNET`, 저장소, 카메라, 알림, 광고 ID 권한이 없습니다.

## 콘텐츠 등급

- 폭력/성/도박/약물/공포: 없음
- 사용자 간 상호작용/위치 공유: 없음
- 광고: 없음
- 예상 등급: 전체 이용가
