# Accessibility and menu redesign — 0.8.30

## Method

Four read-only agents reviewed the 0.8.29 app and public Material 3 / vendor
documentation:

1. Current-app accessibility audit (TalkBack, touch targets, font scale,
   semantics, contrast).
2. Competitor menu/UX survey (GoodNotes, Samsung Notes, Notability, Flexcil,
   Xodo, PDF Expert, Material 3).
3. Whole-app interaction/label plan.
4. Post-merge QA (see below).

Only behavior/patterns were referenced. No third-party code, assets, fonts,
colors, copy, cloud/account flows or branding were copied. The app remains fully
offline with no new permissions.

## Diagnosis

- Touch targets were deliberately 26–40 dp in several places and unit tests
  asserted those small values.
- `selected` / `favorite` / `bookmark` / color state was conveyed by tint, icon
  fill or border, so TalkBack never heard it.
- Split resize was gesture-only for TalkBack; the divider pill had no click
  semantics.
- Several sliders and search fields had no accessible name.
- Fixed `dp` rows with `maxLines = 1` broke at 320 dp / 200% font scale.

## Implemented

### Pure policy

- `AccessibilityPolicy`: 48 dp minimum target, state labels, color-choice labels,
  menu labels, slider labels, disabled reasons, wrap decision.
- `AccessibilityLayout`: `chromeScale(widthDp, fontScale)` decides subtitle
  visibility, title lines, inline action count, dock labels, quick-action columns
  and minimum row height. Boundaries at 360 dp, 1.5x and 2x are JVM-tested.

### PDF viewer / split

- Split chrome target 36 → 48 dp while keeping compact visual icons.
- Divider pill is a labeled 48 dp control (`노트 크기 선택`) with current
  percentage; presets remain available by tap.
- Dock slots, color dots, style pill, sliders, selection actions and text buttons
  are >=48 dp and expose content descriptions/selected state.
- Search field has a visible label; disabled markup actions announce why.
- Viewer root declares `paneTitle`; doc name no longer truncates at large fonts.

### Note editor

- Compact/full dock targets >=48 dp; labels hide at large font instead of
  shrinking text.
- Page pill announces `페이지 n / N`; thumbnails announce page number and
  selected state; add-page buttons >=48 dp.
- Color dots announce color name and selected state; sliders announce label and
  value; section titles are headings.
- Favorite state is state-aware everywhere; toggle rows have one focus target.
- Pen-box/favorite-pen controls are >=48 dp with position-aware labels.

### Home / tools / help

- Home search field labeled; card menus include the subject; stars and cover
  swatches announce state; all card menus >=48 dp.
- Quick actions use 2×2 at narrow/high font, wrap labels, and no longer nest a
  button inside a clickable card.
- Filter/settings rows >=56 dp with headings; Organize wraps to 4 actions at
  narrow widths and exposes page selection state.
- Tools rows >=56 dp and the file picker has an explicit label.
- Help caution blocks show a visible `주의:` label and heading semantics.
- Light `secondary` color darkened from `#B4693C` to `#9A562F` (≈5.6:1 on white).

## Preserved

Offline/no permissions, SAF import/export, working-notebook save and undo,
multi-stroke persistence, Home state restoration, split 35–85% clamp and presets,
favorite pens, pressure profiles, PDF search/markup/page tools, masking cards,
checklists, post-its, audio, backup and export.

## Verification

- JVM: **646 tests**, 0 failures.
- `assembleDebug`, `testDebugUnitTest`, `assembleDebugAndroidTest` pass.
- No `INTERNET`; arm64-only build.
- Real TalkBack traversal and 200% font visual smoke test still require a device;
  no adb device was available.

## QA follow-up before release

A post-merge review found and fixed two blockers:
- the full-screen PDF page pill still used 44 dp targets; it now uses the shared
  48 dp minimum;
- the split divider pill had both a `clickable` and a tap detector on the same
  node, which could make double-tap presets unreliable. It now exposes one
  accessibility `onClick` action alongside the single tap/double-tap detector.

Also wired the large-font title wrap policy into the PDF and note titles, gave
the Reflow overflow a document-specific label, and fixed an E2E test that was
typing into a label node instead of the editable field.
