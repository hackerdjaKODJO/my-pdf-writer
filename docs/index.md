# My PDF Writer

**전공 공부를 위한 오프라인 PDF 필기·편집 앱**

강의자료 PDF 위에 바로 필기하고, 페이지를 정리하고, 주석이 새겨진 PDF로 내보내세요.
광고·계정·인터넷 권한 없이 기기 안에서만 동작합니다.

## 주요 기능

- 펜, 형광펜, 텍스트, 사각형, 화살표, 지우개
- 페이지 회전·이동·삭제·빈 페이지·원본 구성 초기화
- 페이지별 메모, PDF 텍스트 검색
- 화면과 동일한 평탄화 PDF 내보내기
- 완전 오프라인, 광고 없음, 인터넷 권한 없음
