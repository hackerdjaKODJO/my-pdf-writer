My PDF Writer
사용법

PDF를 읽고, 텍스트를 선택해 표시하고, PDF 위에 스터디 노트를 펼쳐 필기하는 방법을 순서대로 정리했습니다. 광고·계정·인터넷 없이 기기 안에서만 동작합니다.

버전 0.8.23 Android 8.0+ arm64 APK 오프라인
앱 안 도움말 첫 실행 안내 설치와 시작 홈 화면 PDF 열기 텍스트 선택·하이라이트 PDF 위 노트 패널 PDF/노트 높이 조절 필기 도구 페이지·템플릿·검색 가림 카드 학습 체크리스트 연속 보기·텍스트 수정 검색 결과 이동 백업·내보내기 문제 해결

다음/이전으로 넘기고 시작이나 건너뛰기로 닫습니다. 다시 보려면 도움말의 튜토리얼 다시 보기를 누르세요.

앱 안 도움말

이 HTML을 열지 않아도 앱 안에서 같은 안내를 볼 수 있습니다.

  • 홈 ⋮ → 사용법/도움말
  • PDF 메뉴 → 문서 → 도움말
  • 노트 ⋮ / 플로팅 독 ⋮ → 도움말
팁: 도움말에는 5분 빠른 시작, 텍스트 선택, 스터디 패널, 가림 카드, 검색, 백업, 문제 해결이 들어 있습니다.

1. 설치와 시작

APK 파일은 소스 저장소가 아니라 다운로드 폴더에 있습니다.

  1. My Files에서 APK 열기
    /sdcard/Download/MyPDFWriter-0.8.23-arm64.apk를 탭합니다. 파일이 보이지 않으면 My Files의 Downloads에서 확인하세요.
  2. 알 수 없는 앱 설치 허용
    처음 설치할 때만 “이 출처의 앱 설치 허용”을 켭니다. 앱 자체는 인터넷을 사용하지 않습니다.
  3. My PDF Writer 실행
    설치는 com.hackerdjakodjo.mypdfwriter.debug로 됩니다. 기존 디버그 버전이 있으면 업데이트로 설치됩니다.
설치가 안 될 때: 이 APK는 arm64 전용입니다. 2018년 이후의 대부분의 안드로이드 폰은 arm64이지만, 아주 오래된 32비트 기기나 일부 에뮬레이터에서는 설치되지 않을 수 있습니다. 그 경우에만 universal APK가 필요합니다.
실행 검증 안내: 이 문서를 만든 환경에는 adb 기기나 에뮬레이터가 없어서 실제 설치·제스처·필압을 자동 검증하지 못했습니다. JVM 테스트 352개와 계측 테스트 APK 컴파일까지 확인된 상태입니다. 설치 후 아래 “문제 해결”의 체크리스트를 확인해 주세요.

2. 홈 화면 — 여기서 시작

앱을 열면 내 노트와 최근 작업이 먼저 보입니다.

  • 이어서 읽기 / 이어서 쓰기: 마지막 PDF와 노트를 바로 엽니다.
  • PDF 탭: 최근 문서를 먼저 보여 주고, 오른쪽 위 도구 아이콘으로 PDF 도구를 엽니다.
  • ＋ 만들기: 어느 탭에서든 새 노트·PDF 가져오기·빈 PDF를 엽니다.
  • PDF 열기: PDF 파일을 가져옵니다.
  • 새 노트: 빈 노트북을 만듭니다.
  • PDF 도구: 합치기·분할·OCR·보안 같은 작업대를 엽니다.
  • 백업/복원: 노트·필기·설정을 ZIP으로 보관합니다.

3. PDF 열기

  1. PDF 열기를 누르고 파일 선택기에서 PDF를 고릅니다.
  2. 페이지가 열리면 상단에 문서명과 페이지, 하단에 도구가 보입니다.
  3. 화면을 두 손가락으로 벌려 확대하고, 한 손가락으로 이동합니다.
  4. PDF 상단의 PDF 메뉴를 누르면 자주 쓰는 7개 도구가 나옵니다. 모든 도구 보기를 누르면 전체 기능이 펼쳐집니다.
PDF 메뉴의 주요 7개: 검색 · 목차 · 북마크 · 페이지 관리 · 주석 목록 · 주석 숨기기 · PDF 내보내기.

4. 텍스트 선택 → 하이라이트

PDF가 텍스트 PDF라면 별도 모드 메뉴를 찾을 필요 없이 하단의 텍스트 선택을 누르세요.

  1. 하단 도구에서 텍스트 선택을 누릅니다. 단어 박스가 표시됩니다.
  2. 한 단어만 선택: 단어를 짧게 탭합니다. 손가락이 조금 빗나가도 근처 단어를 찾습니다.
  3. 더 빠르게: 보기 모드에서 단어를 길게 누르면 선택 모드로 들어가며 근처 단어를 고릅니다.
  4. 여러 단어 선택: 첫 단어에서 끝 단어까지 드래그합니다.
  5. 선택하면 플로팅 선택 바가 나타납니다. 형광펜·밑줄·취소선을 누르면 PDF에 표시가 저장됩니다.
  6. 복사·Google 번역·발췌도 같은 바에서 실행합니다. Google 번역을 누르면 선택한 문구가 항상 클립보드에 복사되고, 번역 앱에서 붙여넣을 수 있습니다.
이미지 PDF(스캔)는 선택할 수 없습니다. “이 페이지에는 선택할 수 있는 텍스트가 없습니다”가 보이면 화면의 OCR 도구 버튼을 누르거나 선택 모드를 종료한 뒤 PDF 도구에서 OCR을 먼저 사용하세요.
표시가 안 보일 때: PDF 메뉴의 주석 숨기기가 켜져 있는지 확인하세요. 숨김은 화면에서만 감추며 저장된 주석을 삭제하지 않습니다.

5. PDF 위 스터디 노트

PDF를 닫지 않고 노트를 펼칩니다. Flexcil처럼 PDF와 노트를 위아래로 같이 보는 화면입니다.

  1. PDF 상단의 노트를 누릅니다. 연결된 스터디 노트가 없으면 새 노트를 만듭니다.
  2. 아래쪽에 노트가 열리고, 위에는 PDF 페이지가 남습니다. 기본 높이는 85%입니다.
  3. 노트 헤더의 PDF 발췌 놓기를 누르면 발췌를 추가할 수 있습니다. PDF에서 선택한 텍스트는 선택 바의 패널에 추가로도 넣을 수 있습니다.
  4. 헤더의 링크 아이콘을 누르면 노트 페이지별 원본 PDF 페이지 목록이 나옵니다. 항목을 누르면 노트와 PDF가 함께 이동합니다.
  5. 노트를 닫아도 자동 저장되고 PDF는 같은 페이지에 남습니다.
화면 구성: PDF의 큰 상단/하단 바는 패널을 열면 사라지고, 뒤로·페이지·텍스트 선택·북마크·도구·메뉴만 PDF 위에 작게 떠 있습니다. 노트 도구도 캔버스 위에 떠 있어서 종이 영역이 넓습니다.

6. PDF와 노트 높이 조절

두 영역 사이의 가운데 손잡이를 위아래로 드래그하세요.

  • 위로 드래그 → 노트가 커집니다.
  • 아래로 드래그 → PDF가 커집니다.
  • 노트는 최소 35%, 최대 85%까지 가능합니다.
  • 노트 헤더의 크기 팝업에서 50/70/85%를 고를 수도 있습니다.

7. 노트 필기 도구

도구사용법
펜색·굵기·펜 종류(볼펜/만년필/붓/연필)를 스타일에서 고릅니다.
형광펜넓은 반투명 획으로 표시합니다.
지우개기본은 닿은 부분만 지우는 부분 지우개입니다. 설정에서 끄면 획 전체를 지웁니다.
올가미필기를 선택한 뒤 편집 시트에서 이동·확대·회전·복사/붙여넣기.
텍스트글상자를 놓고 키보드로 입력합니다.
도형사각형·화살표·선·원. 펜 도형 인식을 켜면 손으로 그린 도형이 자동 정리됩니다.
사진페이지 관리에서 사진 페이지 또는 현재 페이지 배경으로 가져옵니다.
템플릿더보기의 템플릿 스튜디오에서 11종 종이·색·표지·가로/세로를 선택합니다.
필압스타일러스 필압에 따라 만년필·붓 굵기가 변합니다. 필기 설정에서 반응 곡선을 조절합니다.
제스처: 두 손가락으로 짧게 탭하면 실행 취소, 세 손가락으로 짧게 탭하면 다시 실행입니다. 필기 중에는 발동하지 않습니다.
필압은 실기기 검증이 필요합니다. 앱에는 부드럽게/ 선형/강하게 곡선이 들어 있지만, 실제 태블릿의 필압 범위는 기기마다 다릅니다. 기기에서 직접 곡선을 골라 보세요.

8. 페이지·템플릿·검색

페이지 관리

노트 하단의 페이지 pill을 누르면 페이지 관리가 열립니다. 전체/필기 있음 필터, 다중 선택 복제·삭제·회전, 사진 페이지 추가가 가능합니다.

노트 검색

노트 더보기의 노트 검색은 메모·텍스트·스탬프·서명을 찾습니다. 결과를 누르면 해당 페이지로 이동합니다. 손글씨 획 자체는 아직 검색하지 않습니다.

검색 결과 다음/이전

PDF 메뉴의 검색은 페이지별 결과와 하이라이트를 보여줍니다. 결과 목록에서 이전 결과 / 다음 결과를 누르면 결과 페이지로 이동하고 현재 결과가 강조됩니다. 화면 상단의 작은 검색 n / 전체 칩에서도 다음 결과로 이동할 수 있습니다.

팁: 결과는 마지막에서 처음으로 다시 이어집니다. 검색어를 바꾸면 첫 결과부터 다시 시작합니다.
사전: 선택 바의 사전을 누르면 설치된 사전/필기 앱을 선택하는 창이 열립니다. 앱이 없으면 검색어가 클립보드에 복사됩니다.

가림 카드 학습

Flexcil/GoodNotes 스타일의 문제-정답 카드를 오프라인으로 만듭니다.

  1. 노트의 더보기 → 스터디 → 가림 카드를 엽니다.
  2. 카드 만들기로 질문과 정답을 입력합니다. 필요하면 페이지 위 위치와 크기를 퍼센트로 조절합니다.
  3. 페이지에 보이는 테이프를 탭하면 정답이 나타납니다. O / X로 정답 여부를 표시합니다.
  4. 카드 목록에서 진행률과 정답률을 확인하고, 카드를 수정·삭제하거나 해당 페이지로 이동합니다.
주의: 가림 카드는 학습용 오버레이라 PDF 내보내기에는 포함되지 않습니다. 노트 JSON과 로컬 백업에는 저장됩니다. 필기 중 카드 영역이 방해되면 카드 페이지에 표시 스위치를 꺼 주세요.

대화형 체크리스트

Flexcil의 체크리스트 패턴을 오프라인 노트에 구현했습니다.

  • 노트 더보기 → 스터디 → 체크리스트
  • 제목과 항목을 만들고 페이지 위 위치를 지정합니다.
  • 페이지 카드에서 항목을 직접 체크하면 진행률이 갱신됩니다.
  • 전체 항목은 관리 시트에서 수정·삭제하고, 다른 페이지로 이동할 수 있습니다.
  • 필기를 방해하면 카드 페이지에 체크리스트 표시를 꺼 주세요.
주의: 체크리스트는 학습 데이터라 PDF 내보내기에는 포함되지 않지만 노트 JSON과 백업에는 저장됩니다.

연속 보기와 텍스트 수정

PDF 메뉴 → 연속 보기에서 페이지를 세로로 이어서 봅니다. 페이지 번호 라벨은 제거되어 간격이 좁아졌습니다. 확대 메뉴는 없고, 두 손가락으로 핀치하면 현재 페이지만이 아니라 문서의 모든 페이지가 같은 배율로 확대됩니다. 확대 시 상단 퍼센트뿐 아니라 페이지 자체가 실제로 커지고, 좌우로 밀어 확대된 페이지의 다른 부분을 볼 수 있습니다. 확대 상태에서는 페이지가 화면 양쪽 끝까지 이동하고, 한 손가락 세로 드래그는 그대로 스크롤입니다. 대각선으로 드래그하면 가로 이동과 세로 스크롤이 동시에 따라옵니다. 확대 중에는 이전 페이지 화면을 유지해 흰 화면이 깜박이지 않습니다. 한 손가락 세로 스크롤은 그대로 동작합니다.

확대 상태에서는 좌우 드래그로 페이지를 옮길 수 있고, 이 좌우 위치도 모든 페이지에 공유됩니다. 페이지를 더블탭하면 1x로 돌아갑니다. 배율이 바뀌면 화면 크기뿐 아니라 페이지 비트맵도 더 높은 해상도로 다시 렌더링됩니다. 다만 내보내기 PDF의 페이지 크기는 A4로 유지됩니다.

디버그: debug APK에는 우측 상단에 `DEBUG zoom / render / scale` 표시가 나타나고, logcat 태그 `PdfContinuousRender`, `PdfContinuousPinch` 및 NoteTrace의 `PDF_CONTINUOUS`로 실제 렌더 배율과 비트맵 크기를 확인할 수 있습니다.

텍스트를 선택한 뒤 선택 바의 텍스트 수정을 누르면 선택한 문구를 종이색 상자로 덮고 새 문구를 쓸 수 있습니다. 내보내기 PDF에도 같은 화면이 평탄화되어 반영됩니다.

주의: 이는 원본 PDF의 텍스트 데이터를 실제로 바꾸는 기능이 아닙니다. 화면 덮어쓰기이며, 원본 글자는 여전히 검색·추출될 수 있습니다. 완전히 지워야 하면 기존의 가림(REDACT) 도구를 사용하세요.

9. 백업·내보내기

백업/복원

  1. 홈의 백업/복원을 누릅니다.
  2. 백업을 선택하고 저장 위치를 고릅니다. PDF 원본 포함 여부를 선택할 수 있습니다.
  3. 복원은 같은 화면에서 ZIP을 선택합니다. 기존 데이터는 안전하게 교체됩니다.

커스텀 템플릿 이미지·PDF 첫 페이지 배경도 백업에 포함됩니다.

PDF 내보내기

PDF 메뉴의 PDF 내보내기는 화면에 보이는 주석을 평탄화한 PDF를 저장합니다. 노트의 PDF로 내보내기는 전체/현재/선택 페이지와 숨긴 레이어 포함 여부를 고를 수 있습니다.

백업 ZIP은 암호화되지 않습니다. 개인 정보가 들어 있을 수 있으니 신뢰하는 저장소에 보관하세요.

10. 문제 해결

텍스트가 선택되지 않아요

텍스트 선택을 누른 뒤 단어를 탭하거나 드래그하세요. 이미지로만 된 스캔 PDF는 텍스트 레이어가 없어 선택할 수 없습니다. PDF 도구의 OCR로 검색 가능한 PDF를 만든 뒤 다시 열어 보세요.

하이라이트가 안 보여요

PDF 메뉴에서 주석 숨기기가 꺼져 있는지 확인하세요. 숨김 상태는 화면 표시만 바꾸며 데이터는 유지됩니다.

노트가 너무 작아요

PDF와 노트 사이의 가운데 손잡이를 위로 드래그하거나, 노트 헤더의 85% 크기 프리셋을 누르세요. 노트는 최대 85%까지 커집니다.

필기가 사라졌어요

0.8.2에서 다중 획 유실 버그를 수정했습니다. 이미 저장되지 않은 필기는 복구할 수 없으며, 백업이 있으면 백업/복원으로 되살릴 수 있습니다. 현재 버전에서 여러 획을 쓴 뒤 노트를 닫았다 다시 열어 확인하세요.

앱이 설치되지 않아요

arm64 전용 APK입니다. 최신 arm64 폰에서는 정상 설치되어야 합니다. “앱이 설치되지 않음”이 나오면 32비트 기기일 수 있으므로 universal APK가 필요합니다. 저장 공간과 “알 수 없는 앱 설치” 허용도 확인하세요.

PC에서 테스트하려면

저장소를 클론하고 JDK 17·Android SDK 36으로 엽니다.

git clone https://github.com/hackerdjaKODJO/my-pdf-writer.git
cd my-pdf-writer
./gradlew :app:testDebugUnitTest
./gradlew :app:assembleDebug -Parm64Only=true
./gradlew :app:connectedDebugAndroidTest   # 기기 연결 시

계측 테스트 APK만 컴파일하려면 ./gradlew :app:assembleDebugAndroidTest를 실행합니다.
