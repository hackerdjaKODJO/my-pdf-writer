# 개인정보 처리방침

**My PDF Writer** (패키지: `com.hackerdjakodjo.mypdfwriter`)

시행일: 2026년 11월 16일

---

## 1. 요약

My PDF Writer는 대학생의 전공 공부를 위한 **오프라인 PDF 필기·편집 앱**입니다.

- 회원가입·로그인이 없습니다.
- 광고·분석·추적 SDK가 없습니다.
- **인터넷 권한을 선언하지 않습니다.** (OCR 라이브러리가 추가한 권한도 제거)
- OCR은 기기에 포함된 온디바이스 모델로만 처리합니다.
- 사용자가 선택한 PDF와 필기는 **기기 안에서만** 처리됩니다.
- 개발자는 사용자의 문서, 필기, 메모를 수집하거나 전송하지 않습니다.

## 2. 처리하는 정보

### 2-1. 사용자가 직접 선택한 파일

사용자가 Storage Access Framework(SAF)로 PDF를 선택하면, 앱은 원활한 편집을 위해 해당 파일을
앱 전용 저장소(`files/sources/`)로 복사합니다. 이 복사본은 기기 밖으로 전송되지 않습니다.

### 2-2. 필기·페이지 구성·메모·노트북

PDF의 펜·형광펜·텍스트·도형·페이지 회전/순서/삭제·페이지 메모는 앱 전용 JSON 파일
(`files/docstates/`)에 저장됩니다. StarNote 스타일 노트북(제목·커버·템플릿·페이지·필기·태그·폴더)은
앱 전용 JSON 파일(`files/notebooks/`)에 저장됩니다. 이 데이터 역시 기기 밖으로 전송되지 않습니다.

### 2-3. 최근 문서 목록

최근에 연 문서의 이름·페이지 수·마지막으로 연 시각을 `SharedPreferences`에 최대 40개까지
저장합니다. 이 목록은 앱 UI 표시용이며 외부로 전송되지 않습니다.

### 2-4. OCR 처리

스캔 PDF의 OCR은 Google ML Kit의 온디바이스 모델로 기기 안에서 실행됩니다. 페이지 이미지와
인식 결과는 기기 밖으로 전송되지 않으며, 앱은 OCR 결과를 사용자가 선택한 위치에만 저장합니다.
OCR 모델은 APK에 포함되어 있어 별도 다운로드도 하지 않습니다.

### 2-5. 노트북 데이터

노트북은 로컬 JSON으로만 저장되며 계정·클라우드 동기화가 없습니다. 노트북을 PDF로 내보내면
사용자가 선택한 위치에 파일이 저장됩니다. 앱은 노트북을 외부로 전송하지 않습니다.

PDF에서 저장한 발췌, 읽기 진행률·PDF 페이지 북마크, 노트의 페이지 북마크·레이어·펜 프리셋 정보도
앱 전용 저장소(`files/excerpts/`, `files/reading/`, `files/notebooks/`)에만 보관됩니다.
오디오 노트 녹음 파일과 페이지 마커는 `files/audio/`에만 저장되며 외부로 전송되지 않습니다.
로컬 백업은 사용자가 선택한 위치에 **암호화되지 않은 ZIP**으로 저장되며, 복원 시 같은 ZIP을 읽습니다.

**Google 번역**을 선택하면 텍스트가 Google 번역 앱 또는 브라우저로
전달되며, 그 이후의 네트워크 처리와 데이터 처리는 Google의 개인정보 처리방침을 따릅니다.
My PDF Writer 자체는 발췌를 서버에 전송하지 않고 `INTERNET` 권한도 사용하지 않습니다.
소리 내어 읽기는 기기에 설치된 시스템 TTS 엔진을 사용합니다. 일부 TTS 음성은 엔진이 네트워크를
사용할 수 있으나, My PDF Writer는 그 통신에 관여하지 않습니다.

### 2-6. 수집하지 않는 정보

- 이름, 이메일, 전화번호, 주소 등 계정 정보
- 위치 정보
- 연락처, 사진, 카메라
- 마이크 입력은 사용자가 **녹음**을 시작한 동안에만 처리되며 저장/전송되지 않는 오디오 노트 파일로만 남습니다.
- 광고 식별자(Advertising ID)
- 기기 식별자 또는 분석 이벤트
- 사용자가 선택하지 않은 파일

## 3. 권한

앱은 다음 권한을 **선언하지 않습니다**.

- `INTERNET`
- `ACCESS_NETWORK_STATE`
- `READ_EXTERNAL_STORAGE` / `WRITE_EXTERNAL_STORAGE` / `MANAGE_EXTERNAL_STORAGE`
- `CAMERA`
- `POST_NOTIFICATIONS`
- `AD_ID`

PDF 파일 접근은 사용자가 SAF 화면에서 직접 선택한 파일에 한해, 그 순간 부여된 권한으로만
이루어집니다. 앱은 기기 전체 저장소를 스캔하지 않습니다.

`RECORD_AUDIO`는 **오디오 노트 녹음 버튼을 처음 누를 때만** 런타임으로 요청합니다. 녹음을
시작하지 않으면 마이크에 접근하지 않습니다.

## 4. 제3자 제공 및 SDK

- 광고 SDK: 없음
- 분석 SDK: 없음
- 계정/소셜 로그인 SDK: 없음
- 클라우드 동기화: 없음
- 온디바이스 OCR: Google ML Kit Text Recognition (한국어/English). 모델이 APK에 포함되어
  있으며, 이미지·인식 결과를 외부로 전송하지 않습니다. 앱 매니페스트에서 `INTERNET`과
  `ACCESS_NETWORK_STATE` 권한을 제거했습니다.
- 결제 SDK: 없음 (v0.8.3 기준)

따라서 개발자가 제3자에게 사용자 데이터를 제공하는 경우는 없습니다. ML Kit은 기기 내에서만 동작하는 로컬 SDK입니다.

> Google Play 스토어 자체는 Google의 정책에 따라 앱 설치·진단 정보를 처리할 수 있습니다.
> 이는 앱이 수집하는 정보가 아니며, Google의 개인정보 처리방침을 따릅니다.

## 5. 보관 및 삭제

- 앱을 삭제하면 앱 전용 저장소의 PDF 복사본, 필기, 메모, 최근 목록이 함께 삭제됩니다.
- 홈의 **최근 문서 → × → "필기 데이터도 삭제"** 를 선택하면 해당 문서의 앱 전용 복사본과
  필기 데이터를 즉시 삭제할 수 있습니다.
- 사용자의 **원본 PDF 파일은 삭제되지 않습니다.** 앱은 원본을 수정하지 않습니다.
- 내보낸 PDF는 사용자가 선택한 위치(예: Downloads)에 저장되며, 사용자가 직접 관리합니다.

## 6. 아동의 개인정보

앱은 대학생 이상의 전공 공부를 대상으로 하며, 아동을 주 대상으로 하지 않습니다.
아동의 개인정보를 의도적으로 수집하지 않습니다.

## 7. 국외 이전

앱은 데이터를 외부로 전송하지 않으므로 국외 이전이 발생하지 않습니다.

## 8. 방침의 변경

이 방침이 변경되면 이 페이지에 변경 내용과 시행일을 게시합니다.
중요한 변경이 있는 경우 앱 업데이트 노트에도 안내합니다.
